# Ejercicio 1 - Diseño con tarjeta CRC

| Clase: Libro | |
|---|---|
| **Responsabilidades** | **Colaboradores** |
| Conocer su título, autor, ISBN y número de ejemplares disponibles | - |
| Prestar un ejemplar, si hay disponibles | 'Préstamo' |
| Recibir la devolución de un ejemplar | 'Préstamo' |
| Comprobar si hay ejemplares disponibles | - |

## Tarjeta CRC: SOCIO

## Tarjeta CRC: PRÉSTAMO

| Clase: Préstamo | |
|---|---|
| **Responsabilidades** | **Colaboradores** |
| Conocer qué libro y qué socio están implicados | 'Libro', Socio |
| Conocer la fecha de inicio del préstamo | - |
| Registrar la devolución del préstamo | 'Libro' |
| Comprobar si el préstamo está activo o devuelto | - |

## Préstamo de un ejemplar de Libro

Antes de prestar un ejemplar, la clase `Libro` debe comprobar que el número de ejemplares disponibles es mayor que 0.

- Si hay ejemplares disponibles, el préstamo tiene éxito: `Libro` reduce en 1 el número de ejemplares disponibles y se crea un objeto `Préstamo` que relaciona al socio con el libro.
- Si no hay ejemplares disponibles, el préstamo no tiene éxito: `Libro` no modifica el número de ejemplares, no se crea un préstamo y se informa de que no es posible prestar el libro.

## Flujo del préstamo

1. **Se da de alta un libro con 3 ejemplares.**  
   La clase `Libro` guarda el título, autor, ISBN y 3 ejemplares disponibles.

2. **Se dan de alta dos socios.**  
   Se crean dos objetos de la clase `Socio`, cada uno con su nombre, número de socio y fecha de alta.

3. **El primer socio toma prestado el libro.**  
   `Socio` solicita el préstamo. `Libro` comprueba que hay 3 ejemplares, los reduce a 2 y se crea un `Préstamo`.  
   **El préstamo tiene éxito.**

4. **El segundo socio intenta tomar el mismo libro.**  
   `Libro` comprueba que todavía queda 1 ejemplar disponible, lo reduce a 1 y se crea otro `Préstamo`.  
   **El préstamo tiene éxito.**

5. **El primer socio devuelve el libro.**  
   El objeto `Préstamo` se marca como devuelto y colabora con `Libro`, que incrementa sus ejemplares disponibles de 1 a 2.

6. **El segundo socio vuelve a intentar tomar el libro.**  
   `Libro` comprueba que hay 2 ejemplares disponibles, los reduce a 1 y crea un nuevo `Préstamo`.  
   **El préstamo tiene éxito.**
